# Концепт 3 — полная сборка, 16.11.2026

Готовый комплект для репозитория `sarancsk4536-ship-it/koncept_3`.
Внешний вид и навигация сохранены из Концепта 3. Структура — последняя согласованная версия из этой переписки.

## Загрузка на GitHub

1. Распакуйте архив. Загрузите **его содержимое в корень репозитория**, заменив совпадающие файлы.
2. В корне должны находиться `index.html`, `.nojekyll`, папки `dist` и `scripts`, этот README и `RELEASE.json`.
3. Внутри `dist` должны лежать `index.html`, `app.js`, `styles.css`, `catalog.json`, `catalog-data.js`, `favicon.svg` и папка `assets`.
4. Сохраните текущую настройку GitHub Pages. Готовые файлы не требуют сборки, npm или Python.
5. Дождитесь завершения публикации GitHub Pages и обновите страницу сочетанием Ctrl+F5.

Не создавайте дополнительную папку `Koncept3_full_rebuild` внутри репозитория. Нужны именно файлы и папки из архива.

Адреса каталога:
- https://sarancsk4536-ship-it.github.io/koncept_3/
- https://sarancsk4536-ship-it.github.io/koncept_3/dist/

Для локального просмотра достаточно открыть `dist/index.html` в браузере. Данные поставляются локальным JavaScript-файлом, без обязательного сетевого запроса.

## Структура

Четыре входа: «Инструменты», «Оснастка и расходные материалы», «Подбор по этапам работ», «Аккумуляторные платформы».

- 1 625 узлов дерева, 1 400 конечных размещений, 13 этапов работ.
- В этапах категории находятся внутри работ.
- Ручные зубила, наборы ручных зубил и зачистные щетки из примера включены в работу «Разобрать бетонную или кирпичную перегородку».
- Уборка разделена на работы «Удалить строительную пыль» и «Собрать и вывезти строительный мусор».
- Раздел переименован в «Отвертки, ключи, торцевой инструмент».
- Прочие названия и иерархия сохранены. Wesco и P.I.T остаются в группе GreenWorks согласно исходнику; заполнители исходной таблицы не дополнены выдуманными категориями.

Количество конечных размещений включает повторения в разных ветках; это не число SKU.

## Редактирование

Источник — шестиколоночная таблица `scripts/catalog-source.md`.
После правок из корня проекта:

```sh
python scripts/build-data.py --from-markdown scripts/catalog-source.md --snapshot 16.11.2026
python scripts/verify.py
```

Сборщик синхронизирует JSON, локальный файл данных, исходные позиции и версии ресурсов в HTML. Обновляйте весь полученный комплект, чтобы данные и страницы относились к одной версии.

`RELEASE.json` содержит состав и контрольные суммы полной сборки на момент передачи.
