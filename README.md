Источник: приложенная пользователем Markdown-выгрузка шестиколоночной структуры. Подключение к Google Docs не выполнялось; это статический снимок, не автоматическая синхронизация.

## Как применить

1. Сделайте резервную копию текущего проекта.
2. Распакуйте архив в корень проекта. Объедините папки dist и scripts с существующими, подтвердите замену совпадающих файлов. Не удаляйте существующие папки целиком: изображения, styles.css и reference-links.json используются из текущего проекта.
3. Загрузите изменённые файлы в ветку main. Текущие настройки GitHub Pages сохраняются.
4. Дождитесь завершения публикации Pages и обновите страницу сайта (Ctrl+F5).

Сайт уже готов: запуск Python для применения этого обновления не требуется. Пересборка нужна только после последующих изменений источника.

## Что сохранено

Четыре основных входа: инструменты; оснастка и расходные материалы; подбор по этапам работ; аккумуляторные платформы. Названия, порядок и уровни 2–6 соответствуют приложенной таблице. Первый уровень «Ремонт и строительство» остаётся общей страницей. Пометки «вирт» сохранены в данных и дереве. Две повторные позиции одного пути объединяются в один узел, обе строки источника остаются в аудите.

Идентификаторы 851 неизменившегося пути сохранены. Если категория была перенесена или переименована, её прежняя прямая ссылка может перестать работать; переходите к ней через новое дерево или поиск. Товарные данные, наличие и совместимость устройств этим обновлением не проверялись. Ранее существовавшие ссылки DNS добавляются по справочнику reference-links.json.
