# Каталог DIY: структура первого листа

Готовый статический сайт на основе «Лист1», столбцы C:G, снимок от 28.10.2026.
Оформление и иллюстрации взяты за основу из DNS_koncept_2.

## Загрузка на GitHub

1. Распакуйте архив на компьютере.
2. Создайте новый репозиторий GitHub и загрузите в него содержимое архива, сохранив папки и вложенность. Файл index.html должен находиться в корне репозитория. Сам ZIP загружать вместо файлов не нужно.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch, ветку main и папку / (root), затем нажмите Save.
5. После завершения публикации откройте адрес, показанный в разделе Pages.

Чтобы сохранить прежний концепт в существующем репозитории, загрузите содержимое архива в отдельную папку, например sheet1. Тогда новая версия будет открываться по адресу сайта с добавлением /sheet1/.

Файл index.html в корне переводит посетителя в dist/, где находится сам сайт. Внешние библиотеки и установка зависимостей не требуются. Файл .nojekyll отключает обработку Jekyll.

## Что внутри

- dist/: HTML, CSS, JavaScript, данные каталога и все изображения.
- scripts/sheet-source.json: считанный диапазон C:G первого листа.
- scripts/placement-audit.json: связь заполненных ячеек с узлами сайта.
- scripts/reference-links.json: справочник ссылок DNS.
- scripts/build-data.py: повторная генерация catalog.json.
- scripts/verify.py: проверка структуры и ресурсов.

Сайт использует статический снимок и не изменяет Google-таблицу. Названия, порядок и вложенность взяты из первого листа. Существующий шестой уровень сохранён там, где он заполнен в исходных ячейках. Виртуальные категории отмечены отдельно. Ссылки DNS не подтверждают текущее наличие товаров.

## Локальный запуск

Из корневой папки проекта:

```sh
python -m http.server 8080
```

Откройте http://localhost:8080. Для macOS/Linux вместо python может потребоваться python3. Простое открытие index.html двойным щелчком не подходит: браузер может заблокировать чтение catalog.json.

## Обновление данных

После изменения scripts/sheet-source.json выполните:

```sh
python scripts/build-data.py
python scripts/verify.py
```

Поиск, дерево, навигация, представление карточками и списком, а также мобильная версия работают без серверного приложения.
